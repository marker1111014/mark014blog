Telegram 頻道自動同步機制

本網站直接與公開頻道 @mark014blog 連動，無需資料庫或付費主機，只要在 Telegram 發佈或編輯貼文，網站即可自動更新。

方案一 · GitHub Actions 自動排程（目前啟用）

每 15 分鐘自動檢查頻道更新

透過 scripts/sync_telegram.py 定時解析公開網頁預覽 t.me/s/mark014blog，自動同步新貼文、編輯紀錄、瀏覽數與表情反應，產生 data/posts.json 與 feed.xml 後部署至 GitHub Pages。

方案二 · 毫秒級即時觸發（進階可選）

Telegram Bot Webhook + Cloudflare Worker

若需要發完訊息立刻更新，也可部署 worker/telegram-webhook.js 並綁定頻道管理員機器人，透過 repository_dispatch 立即喚醒 GitHub Actions 部署。
